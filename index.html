ZXBOT

A private publishing tool for the Botanical Oddities channel: one odd, true plant fact per short video, made from cited sources. The tool prepares each video on the creator's computer and, once the creator has approved it, sends it to the creator's own TikTok drafts so the creator can add the caption and press Post. It is used by one creator, for that creator's own account only.

What it does with TikTok: Login Kit (the creator signs in once) and the Content Posting API with the video.upload scope (an approved video is placed in the creator's own drafts). It does not read or collect other people's data.
